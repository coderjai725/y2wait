# Y2Wait

Truck freight & return-load matching with reverse bidding, plus a 12-hour bus
parcel express network. Landing site built with React + Vite + Tailwind CSS.

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build to dist/
```

## Configuration

Operator settings (WhatsApp number, Razorpay Payment Button ID, token advance,
corridors, services, roadmap, trust badges) live in `src/config/site.js`.
